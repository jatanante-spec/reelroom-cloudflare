Install ReelRoom

Opens like an app No address bar, no tabs — just your video wall.
On iPhone / iPad (Safari)
  1. Tap the Share button at the bottom of Safari.
  2. Scroll down and choose Add to Home Screen.
  3. Tap Add. ReelRoom appears with your other apps.

Apple does not allow an automatic install button, so these taps are the only way on iPhone.

On Android (Chrome)
  1. Tap the ⋮ menu in Chrome.
  2. Choose Install app (or Add to Home screen).
  3. Confirm. ReelRoom gets its own icon and window.
On this browser
  1. Open your browser menu and look for Install or Add to Home screen.
  2. If there is no such option, this browser cannot install apps — the site still works normally here.

Fire TV / Silk does not offer app installation. Use the 📺 TV mode button instead.
